# 2.2.0 验收范围

本文件记录本地检查范围和正式发布的强制门禁。最终提交、两平台结果与下载哈希以对应 Actions、Release 和签名附件为准。

提交前本地检查（Linux x86_64 容器，系统 Python 3.13，非 Mac/Windows 原生环境）：287 项离线回归无失败，跳过 5 项仅 macOS 或 Windows 原生可运行的 Keychain、迁移、DPAPI 与 Swift 隔离检查（由两平台 CI 执行），外部网络尝试为 0；31 项实际 loopback HTTP 授权检查、22 项登录脚本检查、26 项合成账号浏览器回归通过。浏览器回归按正式页面的内容安全策略（CSP）运行，并检查无违规；界面覆盖 1440/1024/768/390px、完成标记与撤销、Canvas 明确未提交时的二次确认、当前筛选导出、14 天负荷条联动校历、成绩目标测算、侧栏滚动高亮，以及 2.1 既有的组合筛选、日历键盘操作、失败重试、隐藏暂停请求和退出清理。源码及暂存区隐私扫描通过；Gitleaks、工作流语法与历史扫描由 CI 执行。

- 数据完整性：完成标记只写入账号目录的 event-marks.json，最多 400 条，绑定作业身份与截止时间；考试、日期待核对及已变化的事项拒绝标记，失败不写入。标记不改写 Canvas 提交状态，Canvas 明确未提交须携带确认。
- 导出：仅接受当前未来安排中的 id，跳过日期待核对事项，原子写入 account/exports/polyu-schedule.ics（拒绝链接路径），符合 RFC 5545 的转义、75 字节折行与 CRLF；退出登录随账号删除。原生固定操作 exportsFolder 只在访达/资源管理器中定位该目录。
- 成绩：目标测算只在评分方案已核对、无冲突或复杂规则、合计 100% 且已有折算时提供；未公布成绩不按零分计，既有留空规则不变。
- 原生门禁：Mac arm64 文档读取、PDF 表格、空白页 OCR、独立 Keychain 检查、窗口生命周期、完整安装包及 DMG 只读隐私扫描；Windows x64 DPAPI、WebView2、Setup 安装卸载、PE 和注册表版本、完整文件哈希。
- 升级门禁：以 2.1.0 / 构建 210 为基线，检查 2.2.0 / 构建 220 的下载、签名、安装重启、失败拒绝、回退和合成账号资料保护。Mac 使用隔离 Sparkle 测试程序；Windows 旧进程退出为 fixture，新程序真实启动；不据此宣称真实账号升级已验收。
- 正式发布：最终干净 main 提交的跨平台 CI 成功，四个安装包、校验清单和签名更新源一致；当次真实服务及性能收据在 24 小时内且绑定最终提交。

真实服务收据仅覆盖已有授权会话身份核对、Calendar API、已存文档文本解释及账号文件未改。新学校登录、MFA、真实记住密码填入、导出文件在各日历应用中的导入效果和不同 ad-hoc 签名身份的钥匙串授权不由上述检查证明。

性能对照使用下载后校验 SHA256 的正式 2.1.0 安装包及该标签的干净源码，不使用带本地修改的 2.1 目录。两版本同机交替各三轮，原生前台每轮 60 秒、隐藏 30 秒，另测 46 文件/102 页合成冷热缓存。正式 Release 的性能附件由最终提交当次签名收据生成；报告实际数值，不把 CPU 样本换算为物理电池耗电。
