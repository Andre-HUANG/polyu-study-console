PolyU Study Console 1.8.1 隐私与安全修复。

- 本地敏感 API 原生授权会话；公开页面无秘密；一次性票据 30 秒，退出/重启失效。
- Mac Cookie 保存 Keychain，写入/读回复核后迁移，失败保留；Windows 用户 DPAPI。
- 暂存/历史/完整包扫描、160 项回归及实际平台验收；发布依赖可信 main 成功 CI。
- 修复 Windows OCR、WebView2 精简包目录和跨平台构建/验收问题；Setup 安装卸载与 Portable/安装后 GUI 均需验收通过。
- 完善忽略规则和仓库链接；未来提交 noreply，旧历史邮箱尚未清除，重写须另行授权。

Mac：macOS 13+、Apple Silicon，arm64 DMG/ZIP，ad-hoc，未 Apple 公证。
Windows：10 2004+、AMD/Intel x64、.NET Framework 4.8、WebView2 Runtime，Setup/Portable ZIP，未签名。
对照 SHA256SUMS.txt。Windows 卸载保留账号目录，删除资料请先退出登录。
