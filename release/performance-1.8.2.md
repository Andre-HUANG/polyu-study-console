# 1.8.2 早期候选性能对比报告

下述测量来自早期候选 538075e。正式发布门禁要求对最终干净提交重新测量并签名；正式 Release 的同名报告由该测量生成，不能复用本文件作为最终验收。

同一台 Apple Silicon Mac，1.8.1 与 1.8.2 交替运行三轮。每轮显示状态 60 秒、隐藏状态 30 秒；统计应用、Python 后端和本轮新增 WebKit 进程的 CPU 时间。测试用临时独立应用标识和离线合成账号，未访问真实账号。

| CPU 时间中位数 | 1.8.1 | 1.8.2 | 降低 |
|---|---:|---:|---:|
| 请求显示，60 秒 | 0.02917 秒 | 0.02340 秒 | 19.8% |
| 隐藏，30 秒 | 0.11237 秒 | 0.03135 秒 | 72.1% |

显示状态的三轮 CPU 时间分别为 0.02428 / 0.92941 / 0.02917 秒和 0.15893 / 0.02340 / 0.01980 秒，波动明显。操作系统后台负载和窗口遮挡未受控制；显示状态仅请求显示，未持续锁定前台焦点。显示状态唤醒次数中位数为 356 → 379，隐藏状态为 1189 → 617。前台闲置 CPU 降低至少 50% 的目标尚未由这组中位数证明。

CPU 时间根据 proc_pid_rusage 的 Mach 时间单位及 mach_timebase_info 转换；[Apple XNU 源码](https://github.com/apple-oss-distributions/xnu/blob/main/osfmk/kern/bsd_kern.c)提供计数定义。未使用物理功率计或电池放电实验，不能把 CPU 降幅当作续航增幅。实测候选为 538075e；原始二进制哈希、每轮时间和测试边界见同名 JSON。

## 同步与识别复用

相同的 46 个合成文件、102 页，分别进行三轮冷缓存和三轮完整未变化复用；同机使用原生 DocumentReader，统计中位数。

| 项目 | 1.8.1 | 1.8.2 |
|---|---:|---:|
| 冷缓存识别时间 | 1.622 秒 | 1.549 秒 |
| 冷缓存总时间 | 2.391 秒 | 2.338 秒 |
| 未变化复用识别时间 | 0.205 秒 | 0.043 秒 |
| 未变化复用总时间 | 0.988 秒 | 0.825 秒 |
| 未变化复用索引写入 | 15 次 | 1 次 |
| 下载清单写入 | 9 次 | 5 次 |
| 未变化复用正文／OCR／重新解释 | 0 / 0 / 0 | 0 / 0 / 0 |

复用识别时间降低约 79%，总时间降低约 16.5%；索引写入满足不超过 3 次的验收条件。首轮识别的索引写入为 19 → 8 次，保留首次发现、失败和最终结果的即时发布。

独立黄金样本对照比较 98 个文档／页面记录，日期、权重、原文、位置和置信度一致；只排除 PDF 读取方法标签差异。完整证据原始哈希不相同，未声称字节完全一致。

界面闲置状态每 60 秒请求轻量状态，同步时每 2 秒；隐藏或最小化取消状态、内容、搜索和课程表请求。没有数据变化时不整页重绘。低电量模式仅减少闲置检查和动画，OCR 继续尽快完成。

这些性能测量使用合成资料，不能替代真实学校会话或 Windows 性能实测。
