# 2.0.0 验收范围

本文件记录本地验证范围与正式发布的强制门禁。最终提交和两平台结果以对应 Actions、Release 下载及签名附件为准；本地组装不能替代 Windows 原生运行。

提交前本地检查：268 项离线回归通过，Mac 上跳过 1 项仅 Windows 可运行的 DPAPI 测试（由 Windows CI 执行），外部网络尝试为 0；31 项实际 loopback HTTP 授权检查、22 项登录脚本检查、17 项合成账号浏览器回归通过。界面覆盖 1440/1024/768/390px、搜索与组合筛选、日历快速连续键盘操作、同 revision 状态更新、加载失败重试、表单错误、隐藏暂停请求和退出清理。源码、历史泄密扫描及工作流语法检查通过。

- 离线回归：空框架、Canvas/文档解释、日期与评分冲突、个人安排、搜索、会话边界和两平台功能。网络访问在离线 runner 中阻断。
- 界面：隔离合成账号验证搜索、筛选、过期日期语义、状态、错误恢复、键盘和窄窗口；不会访问真实资料。
- Mac：arm64 程序、文档解析器、Keychain 合成读写、原生窗口生命周期、打包与隐私扫描。
- Windows：x64 运行时、DPAPI 合成检查、WebView2 原生窗口、安装/卸载、安装资源与注册表版本、完整包哈希清单。
- 升级：以 1.9.1 为基线演练 2.0.0 的下载、签名、安装重启、失败拒绝和回退；合成账号哨兵不得改变。Mac使用隔离 Sparkle 测试程序，Windows旧进程退出为fixture而新程序真实启动；不据此声称真实账号升级已验收。
- 正式发布要求最终干净 main 提交的 CI 成功，四安装包及更新元数据一致，24小时内的签名真实服务与性能收据有效。

真实服务收据只覆盖已授权会话身份核对、Calendar API、已存文档文本解释和账号文件未改。真实学校新登录、MFA、记住密码自动填入、不同 ad-hoc 签名身份的钥匙串授权仍须分别验收。

性能收据使用同机 1.9.1 / 2.0.0 各三轮原生前台60秒、隐藏30秒与46文件102页合成冷热缓存；结果如实报告，不从CPU样本推算物理耗电，不承诺每台机器或账号均改善。
