# PolyU Study Console 1.8.2
性能与耗电优化，并加入课程表、PolyU 官方校历和签名应用内更新。

- 总览新增上课/考试课程表（本日、本周）与校历，支持来源核对、班组确认、重复安排、停课与补课。
- 前台闲置每 60 秒检查轻量状态；同步期间每 2 秒更新；隐藏/最小化停止界面请求。PDF OCR 阶段复用正文与表格，完整未变化同步复用识别结果。
- Mac 使用 Sparkle 2.10.0，Windows 使用 WinSparkle 0.9.4；正式更新源、包签名与 SHA256 校验。安装版和便携版保持各自使用方式，程序回退不回退账号资料。
- 支持 Apple Silicon macOS 13+ 和 Windows x64（Windows 10 2004+、.NET 4.8、WebView2）。

从 1.8.0/1.8.1 升级：先手动安装一次 1.8.2，再使用设置中的“软件更新”。
现有课程、手动安排、缓存和受系统保护的登录资料保留；退出账号仍会删除全部账号资料。
签名更新用于验证发布来源；当前 Mac 为 ad-hoc 签名，Windows 无 Authenticode 签名，保留系统提示。

验证结果、性能实测和真实学校服务覆盖边界将随最终发布证据更新。
