# 2.1.0 验收范围

本文件记录本地检查范围和正式发布的强制门禁。最终提交、两平台结果与下载哈希以对应 Actions、Release 和签名附件为准。

提交前本地检查：272 项离线回归无失败，Mac 上跳过 1 项仅 Windows 可运行的 DPAPI 检查（由 Windows CI 执行），外部网络尝试为 0；31 项实际 loopback HTTP 授权检查、22 项登录脚本检查、20 项合成账号浏览器回归通过。界面覆盖 1440/1024/768/390px、版本身份、紧迫程度、成绩进度条及未知成绩留空、安排改名与调整课程、组合筛选、日历键盘操作、失败重试、隐藏暂停请求和退出清理。源码及提交历史隐私扫描、Gitleaks 和工作流语法检查通过。

- 数据完整性：手动安排改名或调整课程保留分类、独立来源及省略的权重；重复目标、失效/歧义原记录及文件扫描记录拒绝修改，失败不写回资料。
- 原生门禁：Mac arm64 文档读取、PDF 表格、空白页 OCR、独立 Keychain 检查、窗口生命周期、完整安装包及 DMG 只读隐私扫描；Windows x64 DPAPI、WebView2、Setup 安装卸载、PE 和注册表版本、完整文件哈希。
- 升级门禁：以 2.0.0 / 构建 200 为基线，检查 2.1.0 / 构建 210 的下载、签名、安装重启、失败拒绝、回退和合成账号资料保护。Mac 使用隔离 Sparkle 测试程序；Windows 旧进程退出为 fixture，新程序真实启动；不据此宣称真实账号升级已验收。
- 正式发布：最终干净 main 提交的跨平台 CI 成功，四个安装包、校验清单和签名更新源一致；当次真实服务及性能收据在 24 小时内且绑定最终提交。

真实服务收据仅覆盖已有授权会话身份核对、Calendar API、已存文档文本解释及账号文件未改。新学校登录、MFA、真实记住密码填入和不同 ad-hoc 签名身份的钥匙串授权不由上述检查证明。

性能对照使用下载后校验 SHA256 的正式 2.0.0 安装包及该标签的干净源码，不使用带本地修改的 2.0 目录。两版本同机交替各三轮，原生前台每轮 60 秒、隐藏 30 秒，另测 46 文件/102 页合成冷热缓存。正式 Release 的性能附件由最终提交当次签名收据生成；报告实际数值，不把 CPU 样本换算为物理电池耗电。
