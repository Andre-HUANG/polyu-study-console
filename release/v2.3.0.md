# PolyU Study Console 2.3.0

版本 2.3.0 / 构建 230，以 2.2.0 / 构建 220 为基线。当前为候选源码说明；安装包、签名更新源与正式发布状态以对应 GitHub Release 为准。

- 新增明确的「核实并录入」入口。核对原文后，确认日期、时间、地点或完整评分方案，结果直接用于相关安排、校历或符合条件的成绩折算。
- 已处理事项从待核实列表移除；「核实记录」默认折叠，保留确认值、来源与时间，可撤销。来源变化后旧决定停止应用，事项重新进入待核实。
- 未公布日期单独显示，后续同步继续查找。已获知日期可补充；日期事项不适用时需说明原因，排除后不创建安排，并保留撤销入口。
- 完整评分方案必须合计 100%；复杂规则、隐藏总成绩和未解决的 Canvas 权重冲突不能通过人工确认绕过。未出分或对应关系不明确的成绩继续留空。
- 首页补齐课表待核对入口，课程概况的「下一项」跳过已完成事项。保存失败保留输入；窄窗口核实弹窗首先展示标题、原文和关闭按钮。

核实决定仅保存在当前账号的 `documents/reviews.json`，退出登录随账号删除。来源摘要绑定每次决定，拒绝针对旧来源的保存；原始文件和 Canvas 内容保持只读。已明确的 Canvas 未提交证据仍保留，关联个人安排的完成标记同样需要二次确认。以上界面不增加后台轮询。

升级只替换程序文件并沿用现有本机账号目录；历史 Releases、标签、说明及既有安装包全部保留。目标平台仍为 Apple Silicon macOS 13+（DMG/ZIP）及 Windows 10 2004+ x64（Setup/Portable ZIP）。Mac 为 ad-hoc 签名、未 Apple 公证；Windows 未 Authenticode 签名，依赖已有 .NET Framework 4.8 与 WebView2 Runtime。

本地合成账号回归不代表真实学校登录、MFA、原生 Windows 安装、跨版本账号升级或正式发布已验收。检查范围和待完成发布门禁见 [2.3 验收说明](validation-2.3.0.md)。
