# PolyU Study Console 2.0.0

版本 2.0.0 / 构建 200，以 1.9.1 为基线。

- 首页按登录、会话失效、同步中与部分失败状态给出下一步入口。
- 顶栏资料搜索和 Cmd/Ctrl K 快捷键；考试与作业按名称、课程、地点、备注搜索，支持 7/30 天范围与已过日期视图。
- 已过日期不等于未提交：文档与手动安排保留核对提示，只有 Canvas 明确的未提交状态才作相应标记。
- 校历显示个人安排与选中日清单；改进弹窗错误、重试、键盘导航、字号和窄窗口布局。
- 全部课程页面暂不可读时，保留同一账号此前确认的课程；部分作业接口失败时保留缓存，并明确提示范围不完整。
- 修复复杂评分规则误算等权项目、已提交作业被文档结果重新列入待办，以及截止时刻跨界后缓存不刷新的问题。
- 修复 Windows Setup 欢迎页、文件版本和卸载面板的旧版本号，并将版本核验纳入构建及原生安装验收。

首次启动仍为空框架，没有默认课程、私人账号或预设评分方案。Canvas 保持只读，隐藏窗口暂停前端请求，记住密码默认关闭且始终由用户手动登录和完成学校验证。

从 1.9.1 升级可使用设置中的软件更新，也可手动安装完整安装包。升级只替换程序；学习资料、密码同意状态与退出清理规则沿用原行为。所有历史 Releases、标签与现有资产保留。

提供 Apple Silicon macOS 13+ 的 DMG/ZIP，以及 Windows 10 2004+ x64 的 Setup/Portable ZIP。Mac 为 ad-hoc 签名、未 Apple 公证；Windows 未 Authenticode 签名，仍依赖已有 .NET Framework 4.8 和 WebView2 Runtime。

正式发布需要同一 main 提交的跨平台 CI、原生生命周期/安装/更新/回退检查、隐私扫描、更新签名，以及有效的独立真实服务和性能收据。实际覆盖范围见 validation-2.0.0.md，性能观测见 performance-2.0.0.md / .json。已有会话只读验收不代表新登录、MFA或真实密码填入验收；未测量物理电池耗电。
