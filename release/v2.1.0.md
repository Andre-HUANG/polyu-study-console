# PolyU Study Console 2.1.0

版本 2.1.0 / 构建 210，以 2.0.0 为基线。

- 更新学习总览的排版、卡片、导航图标与窄窗口布局。
- 截止日期增加紧迫程度提示；已过日期仍需结合来源核对，不能仅据此判断未提交。
- 成绩卡片增加进度条，保留原始成绩说明、权重冲突及未知成绩留空规则。
- 手动安排支持修改名称与所属课程，保留原分类、来源和省略的权重，拒绝覆盖同课程同名事项。
- 失效或无法唯一确认的旧安排不会被修改；文件扫描生成的安排继续保持只读。

从 2.0.0 升级可通过设置中的软件更新，或安装完整新版。升级只替换程序文件，沿用现有本机账号与资料；历史 Releases、标签和既有安装包保留。

Canvas 保持只读；程序仍使用本机账号目录，不包含微信小程序或云端资料上传。首次启动为空框架，记住密码默认关闭。

提供 Apple Silicon macOS 13+ 的 DMG/ZIP 和 Windows 10 2004+ x64 的 Setup/Portable ZIP。Mac 为 ad-hoc 签名、未 Apple 公证；Windows 未 Authenticode 签名，依赖已有 .NET Framework 4.8 和 WebView2 Runtime。

正式发布要求同一 main 提交的跨平台 CI、原生生命周期、安装更新回退、隐私扫描、签名更新源和当次真实服务及性能收据。覆盖范围见 validation-2.1.0.md；已有会话只读验收不代表新登录、MFA 或密码填入验收，CPU 观测不等于物理电池耗电。
