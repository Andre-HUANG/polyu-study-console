# PolyU Study Console 1.9.1

本机记住 PolyU Canvas 账号和密码，版本 1.9.1 / 构建 191，以 1.8.2 为基线。

- 「设置 → Canvas 账号」新增「在本机记住账号和密码」，默认关闭，须主动同意。已登录时开启，会在下次重新登录成功后保存。
- macOS 使用独立、不参与 iCloud 同步的 Keychain 记录；Windows 使用当前用户 DPAPI。密码不经过本地 HTTP 后端，不写入日志或安装包。
- 只在匹配的学校主登录页面填入一次；用户手动点击登录并完成学校验证。Canvas 确认账号后才保存；失败或取消不会覆盖原凭据。更换账号需确认替换。
- 可单独删除密码并关闭功能。退出时默认删除密码；每次可主动勾选保留，学习资料和 Cookie 仍全部清除。中断后按已记录选择继续清理。

## 下载与升级

Mac：Apple Silicon、macOS 13+，选择 arm64 DMG 或 ZIP。Windows：Windows 10 2004+、x64、.NET 4.8、WebView2，选择 Setup 或 Portable ZIP。

从 1.8.2 升级可使用设置中的软件更新，也可手动安装。升级后记住密码仍默认关闭。附件包含 SHA256SUMS.txt、签名更新清单及三种原生更新源。

Mac 为 ad-hoc 签名、未 Apple 公证；Windows 安装包未 Authenticode 签名。更新签名用于校验发布来源，不替代上述系统签名。

## 验证范围

244 项离线回归（非 Windows 环境跳过 1 项 DPAPI 原生测试）、31 项回环 HTTP 检查、22 项登录脚本检查；两平台 CI 验证 Keychain / DPAPI、原生窗口生命周期、安装包隐私及更新与回滚。原生凭据界面测试使用合成学校表单和测试记录。

真实学校登录页面上的首次采集、重开填入及 MFA 全流程仍需人工验收；未将合成验证描述为真实 SSO 通过。现有会话的只读服务核验与性能测量另见本次发布附件，CPU 测量不代表电池耗电。
