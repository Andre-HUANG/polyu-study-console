# PolyU Study Console 2.2.0

版本 2.2.0 / 构建 220，以 2.1.0 为基线。

- 作业可标记完成：已完成事项默认隐藏，可通过「显示已完成」查看或撤销；首页数字、最近安排、过期提醒和校历圆点只计未完成事项。
- 完成标记只保存在本机账号目录，绑定截止时间；截止日期变化后自动失效并重新提醒。Canvas 明确显示未提交的作业需要再次确认，Canvas 提交状态不会被改写。
- 「导出日历」把当前筛选中已确认日期的考试与作业写成本机 polyu-schedule.ics（香港时间；有具体时间的提前 24 小时提醒，全天事项前一天 9:00 提醒），可导入系统日历；日期待核对和已过日期的事项不导出，文件随退出登录删除。
- 「接下来的安排」新增未来 14 天负荷条并联动校历；评分方案完整核对后，成绩卡片提供目标测算，未公布成绩不按零分计；侧栏随滚动高亮当前栏目。

从 2.1.0 升级可通过设置中的软件更新，或安装完整新版。升级只替换程序文件，沿用现有本机账号与资料；历史 Releases、标签和既有安装包保留。

Canvas 保持只读；程序仍使用本机账号目录，不包含云端资料上传。首次启动为空框架，记住密码默认关闭。新控件不增加后台轮询。

提供 Apple Silicon macOS 13+ 的 DMG/ZIP 和 Windows 10 2004+ x64 的 Setup/Portable ZIP。Mac 为 ad-hoc 签名、未 Apple 公证；Windows 未 Authenticode 签名，依赖已有 .NET Framework 4.8 和 WebView2 Runtime。

正式发布要求同一 main 提交的跨平台 CI、原生生命周期、安装更新回退、隐私扫描、签名更新源和当次真实服务及性能收据。覆盖范围见 validation-2.2.0.md；已有会话只读验收不代表新登录、MFA 或密码填入验收，CPU 观测不等于物理电池耗电。
