# 1.9.1 验收范围

新增默认关闭、原生授权的本机记住学校账号密码功能。填入后仍由用户手动提交，只有 Canvas 返回已验证账号 ID 才保存候选密码。

244 项离线回归（macOS 跳过 1 项 Windows 原生 DPAPI 检查）、31 项回环 HTTP 检查、22 项学校表单脚本检查。平台 CI 单独执行 Windows DPAPI 和 macOS Keychain 验证。

合成验证覆盖默认关闭、取消授权、写入复核、独立进程重开、原凭据保留、账号替换确认、退出保留或删除及中断恢复。macOS 使用一次性测试钥匙串，Windows 使用测试 DPAPI 记录和 SDK 拦截的合成学校表单；测试不读取真实账号密码。Windows 同时验证 Setup 安装、卸载和 Portable 原生窗口；两平台验证更新签名拒绝、正常更新与回滚。

发布流程要求同一 main 提交的完整 CI、四个安装包哈希及隐私检查、签名更新源检查、只读真实服务凭证和独立性能凭证。真实服务凭证检查现有会话账号归属、日历服务与保存文档的解释，不证明新增记住密码功能的真实学校 SSO 全流程。

真实学校页面上的密码采集、重开填入、MFA，以及不同 ad-hoc 签名身份的跨版本钥匙串授权仍未人工验收。没有把合成测试描述为真实学校登录通过。CPU 与同步测量见 performance-1.9.1.md / .json，未实测电池耗电。
