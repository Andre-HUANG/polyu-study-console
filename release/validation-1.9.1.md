# 1.9.1 候选版验收说明

本次新增默认关闭、原生授权的本机记住学校账号密码功能。填入后仍由用户手动提交，只有 Canvas 返回已验证账号 ID 才提交候选密码。

合成验证覆盖默认关闭、取消授权、写入复核、独立进程重开、原凭据保留、账号替换确认、退出保留或删除及中断恢复。macOS 使用一次性测试钥匙串，Windows 原生验收使用测试 DPAPI 记录和 SDK 拦截的合成学校表单；所有测试均不读取真实账号密码。

本分支是候选版，最终同一提交的 CI 和安装包验证以实际运行记录为准。真实学校账号的密码采集、自动填入、MFA 和跨签名更新须单独验收；没有把合成测试描述为真实学校登录通过。没有声明正式发布或更新源已上线。
