# 2.3.0 验收范围

身份：2.3.0 / 构建 230；升级、回退与性能基线：2.2.0 / 构建 220。当前为候选源码。本文件不代表远程 CI、正式 Release 或签名更新源已经通过。

## 当前本机检查

本次功能实现已在本机 macOS 完成以下检查，使用临时合成账号；未操作正式账号的核实记录或修改 Canvas。身份切换为 2.3.0 后已重跑离线与核实流程贯通回归；本地 Mac 原生 2.3 安装包与最终提交仍待复验，不能把旧 2.2 原生检查、安装包或收据改名当作 2.3 验收。

- 2.3 身份下 305 项离线回归无失败，1 项环境限定检查跳过，外网请求尝试为 0。
- 本次功能实现阶段的 31 项实际 loopback HTTP 授权检查及既有 26 项浏览器回归通过；后者覆盖空账号、组合筛选、手动安排、完成标记与撤销、日历导出、成绩目标测算、键盘、隐藏暂停请求、退出清理及 1440/1024/768/390px 布局。它们不替代最终提交的 CI。
- 新增 12 项真实本机 HTTP 后端与浏览器贯通检查通过：核实入口与未公布日期分区、保存失败保留输入、重载后持久化、安排/校历/ICS 更新、撤销、明确未提交状态二次确认、来源变化失效与拒绝旧请求、不适用原因、时间地点写入、完整 100% 评分方案及仅折算已公布成绩、390px/键盘、退出删除核实记录和清空界面。
- 浏览器检查使用正式 CSP，未发现未捕获脚本错误或 CSP 违规。移动端核实弹窗截图检查确认标题、关闭按钮可见且无页面横向溢出。
- 新增记录及浏览器测试使用合成数据；验证脚本拒绝外部页面请求。测试生成物位于本机 `.build/`，不进入空框架安装包。

## 数据与产品验收规则

- 资料核实通过当前账号的 `documents/reviews.json` 保存，绑定账号和来源摘要，私有原子写入并限制记录数量；注销删除整个账本。来源变化后旧决定停止应用，历史保留；旧摘要提交被拒绝。
- 日期确认后进入对应安排、日历与可导出的未来清单；已核实项目退出待处理清单，核实记录默认折叠并支持撤销。未公布日期不计为真正来源冲突。不适用必须填写原因，不得生成安排。
- 时间地点确认用于对应考试。完整评分方案须合计 100%，且不能绕过复杂规则、隐藏总成绩、数量或匹配歧义及未解决的 Canvas 权重冲突；未公布成绩不按零分计。
- 原始 Canvas 与文件证据保持只读；关联个人或核实安排的明确未提交证据继续保留，标记完成须二次确认。页面操作不增加后台轮询，保存失败保留输入，退出后清空账号相关界面。

## 正式发布仍须完成

- 在最终 2.3 提交上完成跨平台 CI、隐私检查、构建产物身份及哈希核对；四个安装包必须与同一 main 提交一致。只在全部发布门禁满足后发布正式版本。
- Mac arm64 原生文档读取、PDF/OCR、Keychain、窗口生命周期、完整安装包与 DMG 检查；Windows x64 DPAPI、WebView2、Setup 安装卸载、PE/注册表版本及完整文件哈希检查。
- 以正式 2.2.0 / 构建 220 安装包为基线，验证 2.3.0 / 构建 230 的下载、签名、安装重启、失败拒绝、回退和合成账号资料保护。保留旧包及全部历史发布资产。
- 最终提交取得 24 小时内、绑定该提交的真实服务与性能签名收据，生成当次报告与签名更新源。性能报告当前为待测声明，未复用旧版数值。

上述本地合成检查不能证明新学校登录、MFA、真实记住密码填入、真实账号升级、第三方日历应用导入或不同 ad-hoc 签名身份的钥匙串授权效果。尚未声明 Windows 原生验收完成，也未测量物理电池耗电；CPU 采样不能换算为电池能耗结论。
