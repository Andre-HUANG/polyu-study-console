# PolyU study控制台 1.8.0 · 文档识别实现与来源

## 集成的开源组件

- [pdfplumber](https://github.com/jsvine/pdfplumber) 0.11.9（MIT）：依据 PDF 的线条、字符坐标和文字列重建表格，保留多行单元格；识别过程完全在本机运行。
- [pdfminer.six](https://github.com/pdfminer/pdfminer.six) 20251230（MIT）：pdfplumber 的 PDF 字符及布局解析依赖。
- pdfplumber 的运行依赖版本与文件 SHA-256 见 `document-vendor-lock.json`；各依赖的原始许可证随 Python 运行库内的 `.dist-info/licenses/` 等目录保留。
- 扫描页和课件图片继续使用 macOS PDFKit / Vision，Office 文件读取原生 XML 表格及嵌入图片。

## 研究参考

- [Canvas Downloader](https://github.com/BrkBuilds/Canvas-Downloader)：研究课程全量内容采集、增量缓存、分项失败和重试设计；没有复制其 GPL 源代码。
- [Canvas Files API](https://developerdocs.instructure.com/services/canvas/resources/files)：文件元数据、显示名与真实文件名、下载 URL 和访问权限。
- [Docling](https://github.com/docling-project/docling)：研究先恢复文档结构、再解释内容，以及 OCR 与表格结构分离的方式。本应用没有捆绑 Docling 或远程模型服务。

## 本机识别流程

1. 控制台先从登录后的“所有课程”和课程模块网页确定范围，读取模块行的文件 ID，并检查课程页面里的附件链接；不要求个人 API Token。无法访问的网页记录为范围缺口。
2. PDF 增加表格结构解析；PowerPoint 表格保留单元格，Word 连续段落共同解释，避免标题、日期和权重因断行分散。
3. 全部可见附件按课程与 Canvas 模块归档到当前账号的 `documents/files/`；下载清单先报告成功、失败和覆盖缺口。限流 / 短暂网络失败重试，拒绝将 HTML 登录页或截断文件当作成功下载。
4. 下载阶段结束后才开始识别文件。考核安排在识别过程中进入当前账号的证据目录；课件全部图片读取完毕后再次合并。扫描中断时保留已提取结果。
5. 重新扫描时保留本账号尚未复核的旧记录，避免中断清空其他课程。首页、提纲、公告、作业与课程页面中的附件链接也进入下载清单；无法访问的页面明确列出。
6. 显示同步步骤与每门课程的文件覆盖情况。来源冲突、未找到日期、文件读取问题分别呈现。

安装包要求 Apple Silicon、macOS 13 或更新版本（内置 PDF 依赖要求）。不包含课程名单、账号凭据、文件、识别缓存或预设考核规则。
