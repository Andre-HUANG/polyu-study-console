PolyU study控制台 · 1.8.0

适用于香港理工大学学生、搭载 Apple 芯片的 Mac（M1 及更新型号）、macOS 13 或更新版本。

安装
1. 双击「PolyU study控制台-1.8.0-arm64.dmg」。
2. 把「PolyU study控制台.app」拖到旁边的 Applications 文件夹。
3. 从「应用程序」或 Dock 打开应用。
无需安装 Python、Codex 或其他运行环境。

连接 Canvas
安装包是空白框架，不附带任何人的课程、成绩、考试日期、评分权重或登录信息。首次打开点击右上角「设置 → Canvas 账号 → 登录并授权 Canvas」，在学校页面输入 NetID / 密码并完成验证。应用只读取当前账号的 Canvas 课程、作业、公告、成绩及课程文件。

应用先读取 Canvas 网页上每门课的模块和可见附件，按课程、模块和原文件名下载到当前账号的 documents/files 目录；也检查课程页面、提纲、公告和作业中链接的附件。下载阶段结束并汇报数量及失败项后，才逐份提取正文、表格和图片中的考试、Quiz、作业日期、地点与评分比例。明确的日期进入「考试与作业安排」，缺失日期、来源冲突与读取失败分别列出，原文和页码可展开核对。隐藏、锁定或未列出的文件不会显示成下载成功。应用打开期间默认每 1 小时同步一次，也可点击「更新 Canvas」。

考试、作业与成绩
「添加安排」用于核对 Canvas 原文后手动登记，需附 Canvas 链接。课程文件自动识别的安排与 Canvas 截止日期核对，日期冲突保持待核对。成绩只折算有公开数字分数、明确权重及对应关系的项目；未考、未出分、隐藏或权重冲突的部分留空。Canvas 公布的当前成绩单独显示。

版本升级
1.8.0 沿用现有账号目录。从 1.7、1.6 或 1.5 升级时，退出应用后替换应用程序，再重新打开；原有登录、手动安排、文档缓存与评分证据会继续使用。
1.5.0 起不再提供“救驾”项目、周报或本周计划。已登录的 1.4 Mac 应用账号首次运行新版时，会从旧档案迁入 account 目录，保留登录、手动安排、课程文档缓存和评分证据，并清除旧计划与周报。随后重新同步 Canvas。项目目录中的独立旧档案不会导入应用。

资料与退出登录
应用资料位于 ~/Library/Application Support/PolyU study控制台/account/。点击「打开资料文件夹」可查看。退出登录会停止同步、删除这个应用中当前账号的全部资料与会话，并清除学校登录窗口数据；再次登录需要重新采集。退出应用仅关闭服务，已授权资料可在下次启动继续使用。

首次打开的 macOS 提示
此版本使用本地签名，尚未进行 Apple 公证。若 macOS 阻止打开，请先尝试打开一次，再到「系统设置 → 隐私与安全性」点击「仍要打开」。官方说明：https://support.apple.com/zh-cn/102445

数据与来源
学校页面处理账号密码。应用仅保存本机 Canvas 会话，只向学校 Canvas 发出只读请求，文件下载可由 Canvas 跳转至批准的 HTTPS 文件服务器，账号 Cookie 不会随站外跳转发送。控制台服务只监听 127.0.0.1。
CPython 3.12.15 与文档解析依赖的许可证保存在应用 Contents/Resources/Licenses 和 runtime 目录。官方理大标识素材来源见 Contents/Resources/console/assets/SOURCES.txt。此应用为学生制作的个人学习工具，非学校官方应用。

1.7 优化下载与导入：文件传输最多三路同时进行，每个文件校验完成后更新实际完成数；下载失败会列出并在后续同步重试。未变化的文件复用本账号的读取与解释缓存，正文和表格结果仍先于图片识别发布。既有自动同步开关、明确自定义周期和手动安排会保留；手动“更新 Canvas”仍可立即执行。

1.8 界面与日志
日常导航为总览、考试与作业、成绩与评分、课程概况。右上角“设置”随页面滚动保留入口，打开后可选择 Canvas 账号、自动识别、课程概况和运行日志；点击“关闭设置”或按 Escape 返回。课程概况导航会打开设置中的对应栏目。版本号在设置底部显示。
考试与作业新增期末考试筛选；添加安排时也可明确选择期末考试。未公布日期和真实冲突仍列为待核对，来源链接、原文、页码和权重收在“查看详情”中。
运行日志可刷新、筛选失败或清空，只保留最近 200 条固定操作与结果，包含登录/退出的开始、结果和错误；不记录密码、Cookie、Token、学校登录响应、账号姓名或文档正文。登录后的日志只保存在 account/diagnostics 下，随退出账号一起删除。登录前与刚完成退出的结果只在本次运行内显示。清空日志不影响课程、成绩或个人安排。
