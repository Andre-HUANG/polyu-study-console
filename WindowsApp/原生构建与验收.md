# 1.8.1 Windows 构建与验收

本次交付包含真实 Windows CPython EXE、Windows PYD/DLL 和生产桌面入口，产物为 `Win发布/PolyUStudyConsole-1.8.1-windows-x64-setup.exe`、便携 ZIP、SHA256 和 build-evidence.json。使用者无需 Python、Codex 或替我们构建。

Mac 上离线组装官方 Windows 二进制，使用本机编译的 POSIX makensis 与相同 NSIS 3.13 官方 Windows stubs 生成安装 EXE。没有用 Mac PyInstaller 交叉冻结。NSIS 安装/启动引导程序为 PE32 Unicode；Python 和原生扩展为 x64，明确保留的 .NET 托管库为 AnyCPU。

本地 Mac 无 Windows 原生执行环境。组装阶段只检查哈希、PE 架构、METADATA 闭包及 DLL 加载目录，包内 nativeSmoke.status 为 not_run。GitHub Actions 使用 Windows Runner 另行验收运行时、DPAPI、WebView2 GUI、安装/卸载，并生成匹配负载哈希的验证报告。实际执行结果见 SECURITY_TESTS.md 和同版 Release；真实 SSO 尚未验收。未进行 Authenticode 签名。

## 可复现组装

在本版本目录使用已解析的 Python 3.12：

```sh
python3 -B WindowsApp/assemble_windows.py --download
```

`--download` 只补齐 SHA256 锁中的官方公共下载，缓存放本版本 `.build/windows-assembly/downloads/`。缓存齐全时省略它即可离线组装。Mac 统一入口为 `python3 -B build.py --windows`，需要下载时加 `--download`。所有开发工具只放本版本 `.build/`；本命令不安装系统组件或上传源码。远程 CI 与发布另由仓库工作流执行。

`runtime-lock.json` 固定 Astral CPython 3.12.15+20261001 x86_64-pc-windows-msvc、23 个官方兼容 wheel、proxy_tools 源码及补充许可证。METADATA 闭包按 Windows/CPython 3.12 显式解析，不依赖 Mac pip 的宿主 marker。唯一只有源码发行的 proxy_tools 只对原始纯 Python package/PKG-INFO 封装确定性 wheel，不执行 setup.py，不编译本机扩展；所得 wheel 同样有 SHA 锁。

`build-tools-lock.json` 固定 NSIS 3.13 源码和同版本官方 Windows ZIP、SCons、PE 检查/解压工具。用现有 Clang 编译 POSIX makensis，保留构建日志；遵循 [NSIS 官方 POSIX 构建方法](https://nsis.sourceforge.io/Docs/AppendixG.html)。

Python 的 python312._pth 固定私有 runtime、DLLs、Lib、site-packages、WindowsApp 和 console。`-I -B -X utf8` 排除用户 site/PYTHONPATH，不写字节码，明确 UTF8。GUI 用 pythonw.exe，后台/PDF 管道 helper 用 python.exe 和 CREATE_NO_WINDOW，保留 stdout。

console 只复制共享文件与 4 个官方 asset 的明确白名单；桌面入口只复制 5 个明确列出的文件。没有遍历工作区取材料，不包含账号、cookies/token、快照、课程资料或个人评分方案。保留 pywebview 查询所需的空架构目录，剔除 x86/ARM loader、clr_loader 的 x86 DLL 及可选 PDB 调试符号；保留原 x64/AnyCPU 二进制及许可证。原运行时/依赖来自锁定官方下载。

DLL 目录审计单独于 PE import 文件存在性检查：全部 WinRT PYD 与 msvcp140.dll 同目录，CPython 扩展加载包含 DLL 所在目录及 python.exe 目录；SSL/crypto DLL 与相关 stdlib PYD 同目录。clr_loader/pythonnet 使用明确本地 DLL 路径，pywebview 显式加载 Core/WinForms 并加入 x64 loader 路径。上述规则有独立静态检查，并由 Windows CI 执行实际加载及原生验收，范围与结果见 SECURITY_TESTS.md。

安装目录固定在当前用户 `%LOCALAPPDATA%\Programs\PolyUStudyConsole`，无提权或系统组件安装。开始菜单直接启动私有 pythonw.exe。卸载按明确包文件列表删除，并非递归清空；不会访问独立账号目录。WindowsApp/build.cmd 调用相同的哈希锁定组装流程；Windows 原生使用官方同版本 makensis.exe。

## Windows 本机验收

AMD/Intel x64，Windows 10 build 19041 或更新版本；需要现有 .NET Framework 4.8、WebView2 Runtime 与 OCR 语种。应用只读检查，缺少时提示，不自动安装。

1. 双击 `Windows原生自检.cmd`。只使用临时合成资料及临时空账号，检查私有路径、DPAPI、PDF/表格、空白图片 OCR、后台 Job/启停/删除；不读取正式账号或打开学校登录。保留 JSON 或具体错误作为本机证据。
2. 在中文/空格目录验证首开空态、1.8.1、原素材、窗口大小、搜索与来源；worker 不显示控制台。验证重复启动、关闭重开、安装卸载和卸载保留独立账号目录。
3. 在临时合成目录检查长路径/junction 边界、锁文件退出标记、全部 child 停止后删除及后台崩溃。OCR 置信度保持未知；旧 .doc 显示不支持。
4. 学校 SSO、真实课程只读同步、不同账号覆盖拒绝及登录缓存清理需要使用者参与的新鲜登录。学校窗口没有本机桥/secret。不得自动注销已有真实账号作为验收。

只有 CI 实际执行的项目才能记录 PASS；真实账号步骤及其他未执行项目保持 NOT TESTED。旧 .doc 保留原件并显示不支持，使用者可用现有 Word 手动阅读；本版本没有转换件导入及原件关联功能，不自动安装转换器。
