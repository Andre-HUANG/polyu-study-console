# PolyU study控制台 1.9.1

本版本独立源码位于 `版本/1.9.1`。该目录下的 `Mac发布/PolyUStudyConsole-1.9.1-arm64.dmg` 适用于 Apple 芯片 Mac，最低 macOS 13。将应用拖入「应用程序」即可使用，无需单独安装 Python。

Windows 用户使用 `Win发布/PolyUStudyConsole-1.9.1-windows-x64-setup.exe`，或完整解压同目录的二进制 ZIP 后双击 `PolyUStudyConsole.exe`。包内已有私有 x64 Python，普通使用无需构建、Codex 或管理员权限；需要系统已有 .NET Framework 4.8 与 Microsoft Edge WebView2 Runtime。Windows 包已在 Mac 真实组装并完成依赖/PE/DLL 路径静态检查，尚未在 Windows 原生安装或运行；详细条件与已知差异见 `WindowsApp/安装与使用.txt`。

1.9.1 沿用现有账号目录。从 1.8.2、1.7、1.6 或 1.5 升级时，退出应用后替换应用程序，再重新打开即可继续使用现有账号资料。

应用首次启动为空。登录 PolyU Canvas 后，它从网页读取当前账号的课程，先按 Canvas 模块名称下载可见附件，再逐份识别；也会核对课程页面、公告、作业、成绩和评分设置。控制台分别显示下载完成情况与识别结果。应用打开期间默认每 1 小时自动同步，也可点击「更新 Canvas」。

本版本没有周报和本周计划。下载文件保存在当前账号的 `documents/files/课程/模块/文件名`；仅课程页面发现的附件保存在另列文件夹。文件中的日期、时间、地点与评分比例会自动识别，并附 Canvas 原文、文件名和页码。下载失败、无法识别及来源冲突分别显示；隐藏或未列出的文件不会被误报为已下载。

沿用本账号已读资料全文检索，结果保留原始链接、页码/正文位置和读取时间。最近同步尝试与最近完整采集分别显示，部分失败和超过 24 小时未完整采集会提示。首次采集建立基线，之后应用内提示只针对确认的作业、成绩、公告或附件内容变化。本地内容校验正确且 Canvas 提供可靠 ETag 时使用条件下载；其余情况重新下载。正式个人考试表以 eStudent 为准。

现有 1.4 版 Mac 应用的已登录账号会在首次启动新版时迁入 `~/Library/Application Support/PolyU study控制台/account/`，保留手动安排、已下载的文档和评分证据；旧周报与计划会被清除。退出登录会停止同步并删除这个应用中的全部账号资料和 WebKit 登录会话。

安装包不含本项目或任何人的课程、课件、登录凭据和预设成绩权重。应用 Logo、favicon、启动页及图标使用理大官网素材，来源见 `学习控制台/assets/SOURCES.txt`。此应用是学生制作的个人学习工具，不是学校官方应用。

1.7 优化下载与导入：文件传输最多三路同时进行，每个文件校验完成后更新实际完成数；下载失败会列出并在后续同步重试。未变化的文件复用本账号的读取与解释缓存，正文和表格结果仍先于图片识别发布。既有自动同步开关、明确自定义周期和手动安排会保留；手动“更新 Canvas”仍可立即执行。

1.8 界面与日志
日常导航为总览、考试与作业、成绩与评分、课程概况。右上角“设置”随页面滚动保留入口，打开后可选择 Canvas 账号、自动识别、课程概况和运行日志；点击“关闭设置”或按 Escape 返回。课程概况导航会打开设置中的对应栏目。版本号在设置底部显示。
考试与作业新增期末考试筛选；添加安排时也可明确选择期末考试。未公布日期和真实冲突仍列为待核对，来源链接、原文、页码和权重收在“查看详情”中。
运行日志可刷新、筛选失败或清空，只保留最近 200 条固定操作与结果，包含登录/退出的开始、结果和错误；不记录密码、Cookie、Token、学校登录响应、账号姓名或文档正文。登录后的日志只保存在 account/diagnostics 下，随退出账号一起删除。登录前与刚完成退出的结果只在本次运行内显示。清空日志不影响课程、成绩或个人安排。


1.9.1 隐私更新
敏感 API 需要原生随机会话，退出/重启撤销旧凭据。Mac Cookie 保存 Keychain，迁移写入读回复核，失败保留且不回退明文。ad-hoc 更新可能要求钥匙串授权，变更签名升级待实机验收。Windows 保留用户 DPAPI；卸载保留资料，删除请先退出登录。无新增遥测或学习资料上传。


1.9.1 新增
- 设置中的“软件更新”检查 GitHub 正式版，确认后下载、校验并安装重启。1.8.0/1.8.1 需先手动安装本版，之后使用应用内更新。
- 课程表显示上课和考试，可切换本日/本周、核对来源、选择班组、确认或补充安排。作业截止日期继续显示在考试与作业区域。
- 官方 PolyU 校历支持学年切换、教学周和停课提示；学校考试期不是个人考试日期。离线保留上次有效校历。
- 低电量模式减少闲置检查和动画；OCR 继续尽快完成。

1.9.1 本机记住账号和密码
在「设置 → Canvas 账号」手动开启并同意说明，成功完成学校登录后保存；以后只填入一次账号密码，登录按钮和学校验证仍由你完成。此功能默认关闭。
密码只由本机原生窗口和系统保护存储管理。正常关闭或会话到期保留密码；主动退出默认删除，也可当次主动勾选保留。无论是否保留密码，主动退出均删除学习资料和登录会话。
「删除已保存密码并关闭」不影响当前已连接的账号资料。保护或删除失败会显示未完成，禁止回退明文。
